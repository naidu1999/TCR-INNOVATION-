# TCR Innovation — Final Project

Interactive geospatial mapping project built with Python and Folium.

## Contents

- `TCR_Innovation_FinalProject.ipynb` — full project notebook: builds an interactive
  map (`Mapi.html`) from data with **folium** + **pandas**, and saves it to Google Drive.
- `Mapi.html` — the generated interactive map (open directly in any browser).
- `final project.zip` — archived project submission.

## How to view

Open `Mapi.html` in a browser for the finished map, or run the notebook top-to-bottom
(`jupyter lab`) to regenerate it. Requires: `folium`, `pandas`.
